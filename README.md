把 AI 能力拆解为**可复用的办公自动化流程**，并配套可直接使用的企业知识库 Skill。

## Codex AI Knowledge Skill

本仓库同时包含一个面向日常 GitHub 学习的 Codex 知识库技能：

- 路径：`codex/知识库Skill/ai-enterprise-growth-monitor`
- 聚焦：企业 AI 交付、AI 应用落地、短视频运营、客户获取
- 更新脚本：`codex/知识库Skill/ai-enterprise-growth-monitor/scripts/update-github-knowledge.ps1`
- 最新摘要：`codex/知识库Skill/ai-enterprise-growth-monitor/references/latest-digest.md`

每条摘要说明：

- `使用功能`：被监控项目能用来做什么
- `作用`：如何服务于企业 AI 交付、短视频运营、客户获取或 Codex Skill 成长

本地 Windows 计划任务为 `Codex-GitHub-AI-Knowledge-03`（每日 03:00 运行），每次运行后同步受跟踪的技能文件到本仓库并自动推送 GitHub。
